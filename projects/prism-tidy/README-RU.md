# Prism Tidy — страница проекта

**Версия:** beta 2.0 (macOS + Windows)
**Дата:** 2026-11-16
**Назначение:** страница проекта и загрузки приложений.

## Файлы

- `index.html` — страница проекта;
- `downloads/Prism-Tidy-macOS-2.0.zip` — beta-архив macOS;
- `downloads/Prism-Tidy-Windows-2.0.zip` — beta-архив Windows (self-contained .exe).

## Ограничения

- Windows-сборка cross-built и не запускалась на Windows;
- macOS-приложение не нотарифицировано, Windows — без подписи;
- первый запуск на macOS может потребовать «правый клик → Открыть»;
- на Windows SmartScreen может попросить подтверждение;
- ссылка «Все проекты» ведёт на главную Prism.
